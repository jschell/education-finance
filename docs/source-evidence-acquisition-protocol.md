## Fixed scope and hypothesis

The plan identifies source population and original publication vintages as
unresolved barriers that more optimization cannot remove. Pin independently
dated primary evidence and make each missing proof explicit. Select the first
two institution-name leads in the existing review registry, UNITID100654
Alabama A&M and UNITID100663 UAB, without choosing by resulting prices. Inspect
only 2004→2005 identity continuity and 2006/07 price-concept/availability issues.

Fixed retrieval targets:

- NCES 2005 and 2006 Data Feedback Reports for both UNITIDs, at
  `https://nces.ed.gov/ipeds/DataCenter/DfrFiles/IPEDSDFR{year}_{unitid}.pdf`.
- NCES 2006 and 2007 Institutional Characteristics survey instruments, using
  the exact official survey-material URLs verified by primary-source lookup.
- Official UAB Common Data Sets 2004–05 and 2005–06 at the institution's
  `institutionaleffectiveness/images/documents/cds/` archive.

A maximum of eight target PDFs, two explanatory current NCES policy snapshots
and twelve target-PDF URL attempts bounds this pass. Current release guidance
can corroborate DFR provisional-content preservation but cannot certify original
raw CSV bytes or institutional campus populations.
Record absent/rejected/network-blocked results; do not repeatedly retry without
a changed documented retrieval route. Modern NCES guidance may explain the
criteria but cannot replace institution-specific original evidence. Neither a
renamed URL nor successful current download proves historical publication.

## Capture and interpretation contract

Retain public-domain NCES PDF bytes when retrievable; compute SHA-256 and bytes,
record exact URL, retrieval date, MIME/format and extraction tool. Institutional
PDFs may be downloaded temporarily for hash/verification; retain source metadata,
bounded excerpts and extracted numeric/definition fields rather than republishing
whole copyrighted catalogs. Distinguish these states explicitly:

1. Economic concept (cohort, tuition/fees, residency, housing/meal basis).
2. Reporting population (campus/unit aggregation and who reports) for each year.
3. Document's printed publication/date claim.
4. Verified original publication availability of the actual price AND directory
   file bytes at the forecast origin, supported by a contemporaneous capture
   or equivalent independently reviewed release record tied to exact bytes.

A dated report is useful independent price evidence; its printed date does not
verify today's retrospective raw-file vintage. A matching UNITID/name/sector,
matching published prices or generic IPEDS guidance cannot alone certify a
stable reporting population. No current HTTP last-modified date or PDF metadata
creation date becomes original-vintage proof. Unsupported evidence stays null.

Where exact relevant numeric tables are legible, record academic-year label,
price amount, residency/cohort and report page, then compare with the existing
pinned panel for that same definition/year/unit. Never repair or replace panel
values automatically. Conflicting or incomparable values are retained as such.
Do not compare a DFR lowest-residency tuition number with an out-of-state price.
No tuition-only evidence certifies housing continuity or a full paired bridge.

## Eligibility validator and independent review

Implement a separate registry/validator. A source capture must match retained
bytes or its explicitly identified temporary-capture hash record; source claims
must reference capture IDs. Bridging economic comparisons requires approved
concept AND institution-population continuity, an identified exact from/to price
and directory provenance, and independent review. Strict historical eligibility
additionally requires both original price/directory availability proofs at or
before origin; future/retrieved-current documents fail closed. Source-local
progress does not override either model's failed scientific qualification.

Tests must reject unpinned captures, semantic-only claims, population unknown,
late publication/capture, current-release timestamps masquerading as vintages,
one-sided price/directory proof and any production activation/fit request. A
fully synthetic proof fixture verifies the acceptance mechanism without being
mistaken for real institution evidence. Existing original graphs and registries
are immutable; output a separate proposed evidence registry only.

## Deliverables and stopping rule

Produce pinned government source captures where available, machine-readable
capture/claim/eligibility records, reproducible numeric comparison when supported,
meaningful guard tests and a readable evidence-gap report. Obtain independent
source and validator critique; run relevant tests and npm run check. Report count
of captured documents, comparable price checks, independently supported claims,
strict-vintage pairs and authorized bridges, including zero values honestly.
No graph bridge is applied, no historical likelihood runs and no production
change occurs in this pass. If evidence does not establish a requirement, name
the exact missing artifact/provider instead of adding another model layer.
